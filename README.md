# Ply Website

Source for the Ply documentation and website at [ply.web.id](https://ply.web.id).

The Go framework lives at [plygo/ply](https://github.com/plygo/ply).

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
```

The build also generates `public/sitemap.xml` through `next-sitemap`.
