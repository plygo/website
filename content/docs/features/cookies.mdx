# Cookies

Ply wraps fasthttp cookie handling with three context helpers:

```go
value := c.Cookie("session")
c.SetCookie(cookie)
c.DeleteCookie("session")
```

## Set a cookie

`SetCookie` accepts a `*fasthttp.Cookie`. Acquire it from the pool and release
it after the header is written:

```go
cookie := fasthttp.AcquireCookie()
defer fasthttp.ReleaseCookie(cookie)

cookie.SetKey("session")
cookie.SetValue(token)
cookie.SetPath("/")
cookie.SetHTTPOnly(true)
cookie.SetSecure(true)
cookie.SetSameSite(fasthttp.CookieSameSiteLaxMode)
cookie.SetMaxAge(3600)

c.SetCookie(cookie)
```

The response copies the cookie when the header is built, so releasing it after
`SetCookie` is safe.

## Read a cookie

```go
token := c.Cookie("session")
if token == "" {
	c.JSON(401, map[string]string{"error": "missing session"})
	return
}
```

`Cookie` returns the first matching value from the request `Cookie` header.

## Delete a cookie

```go
c.DeleteCookie("session")
```

Deletion sets an empty value, `Path=/`, and an expiry in the past.

## Attributes

| Attribute | Method | Purpose |
| --- | --- | --- |
| Path | `SetPath` | Limits where the browser sends the cookie |
| Domain | `SetDomain` | Limits the cookie to a host and its subdomains |
| Max age | `SetMaxAge` | Lifetime in seconds |
| Expire | `SetExpire` | Absolute expiry time |
| HttpOnly | `SetHTTPOnly` | Blocks JavaScript access |
| Secure | `SetSecure` | Sends only over HTTPS |
| SameSite | `SetSameSite` | Controls cross-site sending |

Use `HttpOnly` and `Secure` for session cookies. Use `SameSite=Lax` or
`SameSite=Strict` unless a cross-site flow requires `None`. `SameSite=None`
requires `Secure`.

## Signing

Ply does not sign cookies. Do not store raw user data in a cookie and trust it
on the next request. Store an opaque session ID and keep the session state on
the server, or sign and verify the value yourself.

## Size

Browsers reject oversized cookies, and cookies are sent with every matching
request. Keep values small and store bulk data on the server.
