# Installation

Ply can be added to an existing Go module or scaffolded with the CLI.

## System requirements

| Component  | Minimum version          |
|------------|--------------------------|
| Go         | `1.26`                   |
| Git        | `2.30` or newer          |
| OS         | Linux, macOS, Windows    |
| RAM        | 512 MB for CLI usage     |
| Terminal   | Bash, Zsh or PowerShell  |

> Go 1.26 or newer is required. fasthttp v1.77 sets the module's `go`
> directive to `1.26.0`.

## Install with the CLI

```bash
npx create-ply@latest my-app
```

See the [CLI reference](/docs/reference/cli) for details.

## Manual installation

<div className='fd-steps [&_h3]:fd-step'>
### Create a project directory
```bash
mkdir my-project
```
### Enter the directory
```bash
cd my-project
```
### Initialize the Go module
```bash
go mod init github.com/yourusername/my-project
```
> Replace `github.com/yourusername/my-project` with your module path.
### Install Ply
```bash
go get github.com/plygo/ply
```
### Create main.go
```go
package main

import (
	"github.com/plygo/ply"
	"github.com/plygo/ply/core"
)

func main() {
	app := ply.New()

	app.Get("/", func(c *core.Context) {
		c.Text(200, "Hello from Ply")
	})

	app.RunServer(":8080")
}
```
### Run the application
```bash
go run main.go
```
> The server listens on http://localhost:8080.
