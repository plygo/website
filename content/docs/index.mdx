# Welcome to Ply

Ply is a thin routing and middleware layer for Go, built on fasthttp. It
provides routing, request contexts and built-in queue, pub/sub and cache
engines, with a small core and no external runtime dependencies.

The documentation covers the following areas:

- Middleware-first routing with handler chaining
- Queue and pub/sub engines
- Context-based dependency injection
- In-memory and file-based caching
- Security headers, body limits, health checks and metrics
- Cookie-backed sessions
- Deployment and testing

## What Ply provides

Ply keeps routing and application logic separate. Handlers are chained,
contexts are pooled, and feature modules can be registered independently.
It includes the engines most services need, so a project can start with
one dependency instead of a stack of plugins.

## Routing model

Ply groups routes into static, parametric and wildcard tiers, then
compiles them into a switch-based table with a radix fallback. Matching is
allocation-free on the hot path, and the compiled table falls back to the
radix tree for route shapes it cannot represent.
